# SjASMPlus signed shifts (#714)

The shared evaluator uses signed 64-bit values and masks shift counts to six bits. SjASMPlus 1.21.0 uses signed 32-bit operands and intermediates; the observed executable masks counts to five bits. Thus `1<<32` must be 1 and `(1<<31)>>31` must be -1. Wrapping only the shifted result is insufficient: `(($7fffffff+1)/2)>>1` needs the addition to wrap before division.

The native fixture captures 646 cases: 636 accepted and 10 refused. Data, EQU, IF sign checks and ASSERT agree in each source. It covers both symbolic and word shift spellings, every count residue, negative and large counts, signed boundaries, arithmetic nesting, unary plus, supported numeric spellings and oversized-literal/division refusals. Both frontends match accepted bytes, formatter idempotence/reassembly and native refusals. The retained red test exposes the original mismatch for `1<<-65`.

The existing private expression parser now lowers signed 32-bit results through the shared 64-bit expression IR and masks source shift counts to 31. Numeric parsing accepts a u32 spelling and interprets its signed 32-bit value; larger literals fail. Arithmetic wraps before enclosing operations. The shared evaluator, Pasmo grammar and public data contracts are unchanged. Bare labels retain their existing IR identity so banked END labels still mark the original entry symbol and page; the broader paged-symbol test caught and guards this requirement.

The primary source declares `aint = int32_t` in [sjdefs.h](https://github.com/z00m128/sjasmplus/blob/v1.21.0/sjasm/sjdefs.h); [parser.cpp](https://github.com/z00m128/sjasmplus/blob/v1.21.0/sjasm/parser.cpp) performs arithmetic with that type. Its C++ shift operators do not explicitly mask out-of-range counts: masking is measured executable behavior, not a portable C++ guarantee. The explicit ignored native test replays the complete fixture and records executable identity, digest, host, exit and bytes. The existing ecosystem workflow runs that bounded control on Linux and retains the report. INT_MIN/-1 division is excluded from this cross-host cohort because the native C++ operation may trap on other hosts.

CLI checks cover Z80/Z80N and human/JSON diagnostics. Included shift expressions match the native image. Oversized literals, division by zero and missing shift symbols report the included file at line 5 and preserve binary, symbols, debug, text listing and JSON listing. The mandatory `sjasmplus_shift_widths` package case replays all 646 native cases with output preservation on refusals, bringing the package cohort to 33 named cases.

The unchanged complete projects remain blocked at separately measured next boundaries: #722 (4510 indirect-Z forms) and #725 (SjASMPlus digit separators). This correction does not claim those projects now build or establish general dialect compatibility.

Validation before the PR: 1,491 workspace Rust tests passed, 38 native-tool tests explicitly ignored; the explicit live SjASMPlus replay passed all 646 cases on macOS ARM. Clippy with Lua/all targets, Rust formatting, generated docs, Ruff and all 46 Node setup/package/source-lock checks passed. The initial full suite exposed the bare-label entry regression described above; after preserving label identity, the paged-symbol and full suites pass.
