# Double-quoted data escapes (#696)

The #695 implementation deliberately refused the 23 backslash pairs that native SjASMPlus decodes. Removing that refusal alone would have emitted raw characters and misidentified commas/comment delimiters after escaped quotes. The new composition fixture first failed with the existing `UnsupportedFeature` diagnostic before this change.

The SjASMPlus item scanner now respects escaped double quotes. Its decoder handles the measured pairs, leaves unknown backslashes literal, and preserves source UTF-8 bytes. Single-quoted character expressions retain their separate parser. No other dialect's grammar changes.

Fresh captures reproduce all 95 printable backslash-pair results and all 51 directive-spelling results from #695 with the same native executable SHA-256. Another 56 cases cover escaped delimiters/backslashes, unknown pairs, marking/termination/offset directives, word/wide packing, UTF-8, empty data, macro/repeat/include composition and malformed inputs. All 202 captured cases match native bytes or refusals in both frontends. Human/JSON CLI checks verify successful bytes and preserved output on malformed input; formatter reassembly is idempotent and byte-identical.

SjASMPlus packs a quoted word/wide string as one big-endian 32-bit value, then emits it little-endian at the chosen width. It does not emit a separate padded value per character. Strings retain their own item boundary for marked and terminated byte directives. Wide data now uses the existing shared Sized data emitter and its truncation/warning policy, rather than strict instruction pieces. The source-bearing capture now includes that emitter so debug/listing byte counts agree with actual output. Six-character packing probes preserve native low bytes; the separate native warning for discarding a string literal's leading bytes above 32 bits is not yet reproduced and remains a follow-up, distinct from output decoding.

The old fixture's `unsupported` flag records which pairs differed from literal bytes in the bounded #695 implementation; historical facts are preserved. Current tests require native bytes for those pairs. Package qualification replaces `unsupported_escape` with `sjasmplus_decoded_escapes`, checking newline, quote and backslash successes and malformed-input preservation. The required cohort stays at 30 named cases; previous reports with the old case name cannot qualify it.

Validation: 1465 Rust tests passed with Lua (37 explicitly ignored reference-tool tests). The external native formatter test was also run explicitly and passed all 95 escaped sources. Clippy with all targets/Lua and denied warnings, formatting, generated docs/workflow checks and 38 Node release controls passed. Ruff passed for the composition capture script. This closes measured data-escape parity, not unrelated string-expression or complete arithmetic-width parity.
